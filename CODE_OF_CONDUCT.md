# Code of Conduct

## Our standard

Be respectful and constructive. Assume good faith. Critique code, not people.

Unacceptable: harassment, personal attacks, discriminatory language, publishing
others' private information, or sustained disruption.

## Scope specific to this project

This is an OSINT tool, so one rule goes beyond the usual:

**Do not use this project's spaces — issues, pull requests, discussions — to
conduct or coordinate an investigation of a real person.** Concretely:

- Never paste real report output, breach data, leaked credentials, or a real
  person's identifiers into an issue or PR. Redact them, or use obviously
  synthetic examples (`user@example.com`, `jdoe`).
- Do not ask for help targeting a specific named individual.
- Do not request features whose only purpose is stalking, harassment, or
  evading a platform's abuse protections.

Maintainers will edit or remove content containing third-party personal data
without waiting for the author.

## Enforcement

Report concerns privately via the contact in [SECURITY.md](SECURITY.md).
Maintainers may remove content, and may block accounts for repeated or
serious violations. Reports are handled confidentially.
